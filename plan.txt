│ PHASE 2: Neue AI-Verhaltensweisen (src/SkyRaider.ts)                     │
│                                                                          │
│ 2.1 Phantom — Stealth/Ambush                                             │
│                                                                          │
│ - Cloak: Startet mit alpha=0.2, unsichtbar für Spieler                   │
│ - Bewegung: Catmull-Rom-Spline durch 5 Zufallspunkte im Spielfeld,       │
│ erneuert alle ~3.2s. Glatter, unvorhersagbarer Pfad.                     │
│ - Angriff: Bei nextShotAt + Ziel in 300px Reichweite → Decloak (alpha    │
│ tween 0.2→1.0, 400ms) → einzelner hochpräziser Schuss (kleine Streuung,  │
│ 1.3x Geschwindigkeit) → nach 1.2s Recloak                                │
│ - Neue Felder: cloakAlpha, isCloaked, recloakAt, splinePoints[],         │
│ splineProgress, splineRefreshAt                                          │
│ - Catmull-Rom Helper: Private Methode mit Standard 0.5-Tension-Matrix    │
│                                                                          │
│ 2.2 Bomber — Schwerer Gebietskontrolleur                                 │
│                                                                          │
│ - Bewegung: Langsame horizontale Sinuswellen-Patrouille bei              │
│ enterTargetY, kein Dive-Verhalten                                        │
│ - Angriff: fireClusterBomb() statt fireShot() — feuert 3-5 Projektile    │
│ gleichzeitig als Fächer (spread ±0.35 rad), zielend auf                  │
│ Spieler-X-Region. Langsamere Feuerrate (1.5x Intervall).                 │
│ - Shot-Tint: Bomber-Shots orange getönt (0xffaa66), 1.3x Skalierung      │
│                                                                          │
│ 2.3 Interceptor — Formations-Paar                                        │
│                                                                          │
│ - Spawn: spawnRaider() erstellt ZWEI Raiders wenn Variant='interceptor'  │
│ (braucht 2 freie Slots)                                                  │
│ - Neue Felder: formationPartner, formationSide (-1/1),                   │
│ bezierStart/Control/End, bezierProgress, bezierActive                    │
│ - Bewegung: Beide halten formationSpacing (80px) Abstand, Center-X       │
│ trackt Spieler mit Dämpfung (lerp 0.04)                                  │
│ - Bezier-Arcs: Alle 2-3s initiiert ein Ship einen Bogen-Angriff          │
│ (quadratische Bezier-Kurve von aktueller Position, Kontrollpunkt         │
│ seitlich, Endpunkt Richtung Spieler). Dauer 1.8s.                        │
│ - Burst-Fire: 3 Schüsse mit 80ms Abstand während Bogen-Mitte (Progress   │
│ 0.3-0.7)                                                                 │
│                                                                          │
